## Iteration 56 - US-055: Add safety layer for computer control
- Created `rex/computers/safety.py` with `ActionType` enum, `classify_action()`, and `SafetyLayer` class
- Safe actions: `read_file`, `list_dir`, `search_files`, `summarize_file`
- Dangerous actions: `write_file`, `delete_file`, `execute_command`, `launch_app`; unknown → treated as dangerous
- `SafetyLayer(mode)` supports `"always"`, `"dangerous_only"` (default), `"never"`
- `SafetyLayer.check(action, description, confirm_fn)` calls confirm_fn only when needed; denies if no fn and confirmation required
- Added `computer_control_confirmation: str = "dangerous_only"` to `AppConfig`
- 29 tests in `tests/test_us055_safety_layer.py`: classify, requires_confirmation, check flows, AppConfig field
- Files changed: `rex/computers/safety.py` (new), `rex/config.py`, `tests/test_us055_safety_layer.py` (new), `PRD.md`
- Learnings:
  - `confirm_fn: Callable[[str], bool] | None = None` cleanly models optional confirmation callbacks
  - Unknown actions default to dangerous for safety (fail closed)
  - `SafetyLayer.from_config()` classmethod handles config-load failures gracefully
