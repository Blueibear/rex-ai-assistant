## Iteration 2 - US-002: Replace raw python calls in bridge scripts with venv resolver
- Added `from rex.bridge_utils import resolve_python` and `_PYTHON_EXE = resolve_python()` to all 16 root-level rex_*_bridge.py files
- None of the bridge files had subprocess calls; criteria 2 and 3 were trivially met
- ruff auto-fixed 10 pre-existing UP017 violations (timezone.utc → datetime.UTC) during lint pass
- Files changed: all 16 rex_*_bridge.py, PRD.md
- Learnings for future iterations:
  - Bridge files are stdin/stdout JSON processors — they don't spawn subprocesses themselves
  - Module-level `_VAR = func()` is NOT flagged as unused by ruff (F841 only applies to locals)
  - ruff and black must be installed via pip (not in venv by default); run `pip install ruff black mypy`
  - Pre-existing unused-ignore mypy warnings exist in bridge files from `# type: ignore[import]` comments
