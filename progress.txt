## Learnings
(Patterns discovered during implementation — add entries here as work progresses)

- "Verify changes work in Electron" criteria cannot be tested via browser/kapture because the renderer requires `window.rex` (Electron IPC preload bridge). Verification is done by: (1) code review confirming implementation, (2) TypeScript compile success, (3) Electron dev server starts without errors, (4) bridge scripts validate. The Electron window opens on the user's desktop when `npm run dev` is run from gui/.
- The Vite renderer dev server runs at http://localhost:5173/ when `npm run dev` is run from gui/. Port 5173 will be LISTENING while it's active.
